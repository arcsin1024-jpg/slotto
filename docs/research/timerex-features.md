# TimeRex 機能調査(Slotto 設計用)

- 調査日: 2026-10-02
- 対象: 日程調整SaaS「TimeRex」(https://timerex.net/ 、運営: ミクステンド株式会社 / MIXTEND)
- 目的: 同等機能を持つ自社サービス「Slotto」(Web + モバイルアプリ)の設計書を書くための、機能一覧と画面構成の把握
- 調査方法: 公式サイト・公式ヘルプセンター(help.timerex.net)・公式ブログ・レビューサイトを WebSearch / WebFetch で取得。画面レイアウトは、ヘルプ記事に貼られた公式の画面キャプチャ(ホーム、作成画面、詳細ページ、ゲスト側3画面)をブラウザで開いて目視確認した。**実際にアカウントを作って管理画面を操作したわけではない**
- 表記ルール: 事実はヘルプ等の記述ベース。筆者の推測には「(推測)」と明記。確認できなかった項目は「未確認」と明記
- 注意: WebFetch は取得したページを要約して返すため、細かい文言や数値に要約由来の誤りが残っている可能性がある。設計の根拠にする数値(上限値など)は、末尾の参照 URL で原文を確認するのが安全
- 進捗: 全11章を記入済み(2026-10-02)。未確認事項は末尾にまとめた

### 最重要ポイント(先に読む用)

1. **課金軸は「人数・カスタマイズ・CRM連携」**。日程調整カレンダー数と調整回数は無料でも無制限。フリーは参加メンバー2人まで。ベーシック 750円〜、プレミアム 1,250円〜(1ライセンス/月、年払い、税抜)
2. **ログインは Google / Microsoft の OAuth のみ**で、ログイン = カレンダー連携。メール+パスワード登録なし
3. **空き判定はカレンダー側の予定ステータス任せ**。未回答・仮承諾の招待は「埋まり」、辞退と「予定なし/空き時間」は「空き」。**予定単位で除外/反映を選ぶ機能はない**
4. 複数人調整は「全員が参加(AND)」「誰か1人が参加(OR)」「2つのグループから1人ずつ」の3方式 + 自動アサイン(均等 / 優先度順)
5. ゲストはログイン不要の3画面(日程選択 → 情報入力 → 完了)。5日分の週グリッドでティール色の枠をクリック。確定は即時(承認制なし)。ゲストへは ICS 添付メール
6. ホスト側から日程変更はできない(キャンセルのみ)。ゲストのキャンセル/リスケを完全に無効化する設定は見当たらない(期限を最大720時間前にして代用、とのレビューあり)
7. **ネイティブアプリは見当たらない**(Web のみ。一部の作成機能は PC 限定)。決済機能・場所指定(対面/電話)も公式資料にはない
8. 予約ページ URL は `https://timerex.net/s/<チームID>/<ランダムなカレンダーID>/`。カレンダーID は変更不可

## 1. 料金プランごとの機能差

### 1.1 プランと価格(公式 https://timerex.net/plan 、2026-10 時点)

| プラン | キャッチコピー | 年払い時(1ライセンス/月) | 月払い時(1ライセンス/月) |
|---|---|---|---|
| フリー | 日程調整自動化へのエントリー | ¥0 | ¥0 |
| ベーシック | ビジネスを加速させる日程調整 | ¥750(税抜) | ¥900(税抜) |
| プレミアム | セキュリティと柔軟なカスタマイズ | ¥1,250(税抜) | ¥1,500(税抜) |
| エンタープライズ | (40名以上での導入時に別途対応、要問い合わせ) | 非公開 | 非公開 |

- 課金単位は「ライセンス/月」。ユーザー数に応じた従量課金(例: ベーシック年契約 10 人 = 750円 x 10 = 7,500円/月 税抜)
- 年払いは月払いより約16%割引
- 契約は**チーム単位**。個人・法人の区分なし。アカウント登録時に自動でフリープランのチームが1つ作られ、チームオーナーがアップグレードする
- チーム内でプランと契約期間(月払い/年払い)は統一が必要。契約期間中のライセンス解約(減数)は不可、更新時に減らせる
- 購入済みで未割り当てのライセンスにも料金が発生
- 支払い方法: クレジットカード(全プラン)。請求書払いは「法人・プレミアム・年間契約・2ライセンス以上」のみ
- 返金は原則不可
- フリープランは永年無料・クレジットカード登録不要
- プレミアムプランの**14日間無料トライアル**あり(開始当日から14日後の 23:59 まで。開始時に自動で50ライセンス付与。本契約しなければ自動でフリーに戻り、**フリー外機能を使った設定はすべて削除され復元不可**)

### 1.6 Slotto への示唆(筆者メモ)

- TimeRex はカレンダー数・調整回数を無料でも無制限にし、**「人数」「カスタマイズ」「CRM連携」で課金**している(競合の Calendly / Spir などが「カレンダー数」で絞るのと対照的)
- フォームのカスタム質問がプレミアム限定(月 ¥1,250〜)なのは、個人・小規模ユーザーには割高に映る箇所(推測)

## 2. ホスト側の機能(日程調整カレンダーの種類と設定項目)

### 2.1 日程調整方法の種類(公式ヘルプ「目的に合わせた日程調整方法の選び方」)

| 種類 | 概要 | 候補の出し方 | URL の使い回し | プラン | 備考 |
|---|---|---|---|---|---|
| 日程調整カレンダー | 基本形。連携カレンダーの空きを自動表示し、継続的に予約を受け付ける | 自動(連携カレンダーの空き) | 何度でも使える固定 URL | 全プラン | TimeRex の中心機能 |
| ワンタイムURL | 日程調整カレンダーから派生して発行する「1回だけ使える URL」 | 自動(元の日程調整カレンダーの設定) | 1回の日程調整完了で無効 | 全プラン | 同じ人からの重複予約防止 |
| 候補を選んで日程調整 | ホストがカレンダー上で候補日時を手動で選んで提示 | 手動(最大20枠) | 1 URL につき1回のみ | 全プラン(人数: フリー2名 / 有料3名) | 候補は**仮予定**として参加メンバーのカレンダーに登録される |
| グループ投票 | ホストが候補を提示 → 複数ゲストが各候補に ○/× → ホストが確定 | 手動(フリー最大6枠 / 有料最大10枠) | 投票用 URL | 全プラン | 3者以上の調整向け |
| セミナー機能 | 1つの開催日時に複数名の予約を受け付ける | 手動(開催日時を指定) | 固定 URL | プレミアム | 即予約 / **仮予約(承認制)** を選択可 |
| ルーティング | 質問への回答に応じて、表示する日程調整カレンダーを出し分ける | - | 固定 URL(1本) | プレミアム | チームスペースのみ |

- 「1回限り」に相当するのは **ワンタイムURL**、「候補を手動で選ぶ」に相当するのは **候補を選んで日程調整**、「チーム」は日程調整カレンダーの**参加メンバー/参加方式**の設定で実現する(別種のページがあるわけではない)
- **承認制(仮予約)は通常の日程調整カレンダーには見当たらない**。確認できたのはセミナー機能の「仮予約(ホストが参加承認すると確定)」のみ。通常の日程調整カレンダーはゲストが選んだ時点で即確定(ヘルプ記事の範囲では承認フローの記述なし)

### 2.2 日程調整カレンダーの作成フロー

1. マイスペースまたはチームスペースのホーム画面 → 「日程調整カレンダー」タブ → 「+ 日程調整カレンダー作成」
2. 基本項目(予定名、所要時間、前後の確保時間、参加メンバー、参加方式、Web会議設定)を入力。細かい項目は「詳細設定」を開いて設定
3. 「作成する」をクリック(カレンダー名未入力、カスタム値に半角数字以外があるとボタンが押せない)
4. 発行された URL をコピーしてゲストに案内

- 編集は「保存する」ボタンで確定。編集の入口は 3 つ: (a) ホーム画面でカレンダー右上「︙」→ 編集 (b) カレンダー詳細ページの編集ボタン (c) ログイン状態で予約ページ URL を開くとページ上部に「ページを編集する」ボタン
- 複製: 「︙」→「複製」。所要時間・確保時間・参加メンバー・Web会議・提示期間・メッセージなど全設定を引き継ぐ。スペース/チームをまたぐ複製も可(その場合、参加メンバーなどチーム依存の設定は保持されない)
- 削除、フォルダへの分類も可

### 2.3 設定項目の詳細(日程調整カレンダー)

**A. 基本設定**

| 項目 | 仕様 | プラン |
|---|---|---|
| 日程調整カレンダー名 | ゲストに表示される名前(例: 「お打ち合わせ」) | 全 |
| 非公開カレンダー名 | 「非公開カレンダー名を設定する」をオンにして入力。ゲストには非表示。社内で用途・流入元を見分ける用(例: 「商談(A施策経由)」) | 全 |
| 所要時間 | プリセット + カスタム。**10分以上・1分単位・最大480分** | 全 |
| 前後の確保時間 | プリセット **0分 / 30分 / 45分 / 60分** + カスタム(0〜180分、1分単位)。前と後で別の値にできる。片方だけも可 | 全 |
| 確保時間の予定名 | デフォルト「確保時間」。チェックを入れて「移動時間」「準備時間」などに変更可 | 全 |
| 参加メンバー / 参加方式 | 4 章参照 | 人数・方式に制限 |
| Web会議設定 | 「利用しない」/ Zoom / Google Meet / Microsoft Teams | 全 |
| ゲストに対して Web会議URL を非公開にする | オンにすると URL は発行されるがゲストには見せない(完了画面・完了メールには「別途、主催者からの連絡をお待ちください」と表示。ホスト側の予定・カレンダー・通知メールでは確認できる) | ベーシック以上(2026-08 の公式ブログ記載) |
| 会議室設定 | 「日程調整完了時に会議室を予約する」をオン → 最大5つの会議室を優先順位付きで選択。空いている中で優先度の高い1室を確保。ゲストには会議室情報は非公開 | ベーシック以上 |

- 前後の確保時間の動作: 「所要時間 + 前後の確保時間」が丸ごと空いている枠だけを候補に出す。確定時は**ホスト側の連携カレンダーにのみ**確保時間の予定が別予定として登録される(所要60分・前後30分なら予定が3つ入る)
- 対面・電話・任意の場所(住所)を指定する「場所」設定は、Web会議連携の記事には記載なし(未確認。メッセージ欄に書く運用と推測)

**B. 日程候補設定(詳細設定)**

| 項目 | 仕様 | プラン |
|---|---|---|
| 曜日ごとの受付時間 | 曜日ごとに時間帯を [00:00] 形式で入力。**1日あたり最大5枠**の時間帯。「他の曜日にも適用する(上書き)」で一括コピー可。初期値は「アカウント設定 > スケジュール > 曜日と時間帯のデフォルト設定」 | 全 |
| 特定の日の受付時間を変更 | カレンダーから日付をクリックして個別設定(その日だけ別の時間帯、または「この日に予定を受け付けます」のチェックを外して受付不可)。設定可能範囲は当日〜6ヶ月後の月末。個別設定した日は太字表示 | ベーシック以上 |
| タイムゾーン | 受付時間帯の基準タイムゾーン。初期値はアカウント設定のタイムゾーン | 全 |

| 日程候補の表示間隔 | 「自動」(所要時間と同じ間隔)/ 15分 / 30分 / 60分 / 120分 / カスタム(10〜120分、1分単位)。所要時間は変わらない | 全 |

| キャンセル・リスケジュール期限 | 開始時刻の何時間前まで受け付けるか(0〜720時間、1時間単位)。未設定時は**予定の終了時刻まで**キャンセル・リスケ可 | ベーシック以上 |

- 提示期間「日付を指定」の終了日を過ぎてアクセスすると「アポイント一覧を取得できませんでした ただいま受付期間外です。」と表示
- 営業日ベースの「N営業日後から」指定は記載なし(時間単位のみ)
- 「何時間前まで受付」は「何時間後から先の候補を提示するか」で表現(例: 24 を入れると 24 時間後以降のみ表示)

- 設定は元の日程調整カレンダーをそのまま使う(個別設定の記載なし)

### 2.5 候補を選んで日程調整

- 作成: (必要なら先にフォルダを選択)→「+ 候補を選んで日程調整する」→ 基本設定(予定名、所要時間 15〜480分・1分単位、参加メンバー、Web会議、プライバシー)→ カレンダー上で候補日時を**クリック**して選択(選択枠は緑、x ボタンで削除、**最大20枠**)→ 作成 → URL コピー
- 候補は参加メンバーの連携カレンダーに**仮予定**として登録(連続する候補は1つにまとめる)。編集すると仮予定も連動。確定時に選ばれなかった仮予定は削除
- 1 URL = 1回限り。別のゲストには新しく作る
- ゲスト側: 緑の候補から選ぶ。過ぎた候補はグレーアウト
- 制限: 作成は **PC のみ**(ゲスト側の確定はスマホ可)/ 複製不可 / CSV 不可 / チャット連携不可 / **マイスペース非対応(チームスペースのみ)**
- リマインドは日本時間の前日16時固定、キャンセルは予定終了時刻まで

### 2.6 グループ投票

- 作成: 「グループ投票」タブ →「グループ投票を作成」→ 予定名、所要時間(15〜480分)、参加メンバー、Web会議、タイムゾーン → 候補を選択(フリー最大6枠 / 有料最大10枠)→ URL コピー
- 依頼方法: (A) URL を共有 (B) 作成完了直後の画面からメール送信(ゲスト名任意 + メール必須、最大10人。この画面でしかできない)
- ゲスト: 候補ごとに ○ / × を回答、名前・メールアドレスを入力して送信。アカウント不要。**回答後の変更不可**
- ホスト: 「日程調整中」タブ / 「確定した予定」タブ。詳細画面で各候補の「確定する」→「日程を確定する」
- 確定後: 参加者全員に完了メール(ICS 添付)。Web会議 URL 自動発行
- 制限: 作成後の編集不可 / 確定後の日時変更不可 / キャンセルはホストのみ

### 2.7 セミナー機能(プレミアム)

- 作成: 「セミナー機能」→「新しいセミナーを作成」
- 基本: セミナー名(必須)、非公開メモ、サムネイル画像(10MB以内 jpg/jpeg/png)、セミナーページ説明文
- 申込受付方法: **即予約**(申込と同時に確定)/ **仮予約**(ホストが参加承認すると確定。ゲストには「参加をリクエストしました」→ 承認後に確定メール)
- 開催日程: 開催日、開始・終了時間、ウェビナーURL または住所(必須)、参加上限人数、受付締切日時(未設定なら開始時刻まで)。複数開催日を設定可
- 質問: デフォルト4項目 + テキスト / 複数行 / チェックボックス / ラジオ / セレクト
- メール: 通知メール(最大5アドレス)、申込完了メール、リマインド(開始24時間前)、フォローアップメール(終了後、最大24時間後まで)
- ゲスト一覧・CSV 出力・レポート機能あり。パラメータ連携・英語は非対応

### 2.8 ルーティング(プレミアム、チームスペースのみ)

- 作成: 「日程調整カレンダー」タブ内の「ルーティング」タブ →「+ ルーティング作成」
- 設定: ルーティング名 / 非公開ルーティング名 / 開始時メッセージ → 質問(デフォルト4項目 + テキスト・複数行・チェックボックス・ラジオ・セレクト)→ 受付状況・通知先 → ロジック
- ロジック: 条件(テキスト: 一致する / 一致しない / 含む / 含まない。選択肢: いずれかに一致 / いずれにも一致しない)を AND で複数。アクションは「日程調整カレンダーを表示する」または「メッセージを表示する」(= 日程調整させない)。上から順に評価。「すべてのロジックに該当しない場合のアクション」は必須
- 振り分け先は同じフォルダ内の日程調整カレンダーのみ。ルーティングと振り分け先で質問タイトル・選択肢が完全一致する項目は回答を引き継ぐ
- 制限: 作成は PC のみ / 複製不可 / Google Sheets・CSV・チャット連携・ウィジェット埋め込み非対応 / 作成後のフォルダ移動不可

### 2.9 予定(確定済み)の管理

- 確認場所: (A) 日程調整カレンダー詳細ページの「確定した予定」タブ(キャンセル/リスケ済みは非表示)(B) ホーム画面の「予定」タブ(「これからの予定」/「過去の予定」)
- 予定詳細: 日程調整カレンダー名、日時、所要時間、前後の確保時間、ホスト側参加者、Web会議URL、会議室、ゲスト情報(名前・メール・会社名・コメント)、質問への回答とアップロードファイル、送信日時、**メール送信履歴**、リスケ前後の予定へのリンク
- 未来の予定は「予定をキャンセルする」ボタンでキャンセル可。キャンセル済みは「キャンセル済」として「予定」タブに残る
- **ホストからのリスケジュールは不可**(一度キャンセルして再調整を依頼するしかない)。キャンセル時のコメント欄に日程調整カレンダーの URL を書いて再予約を促す運用が公式で案内されている
- ホストのキャンセル手段: 完了メールの「予定をキャンセルする」/ 連携カレンダー上の予定に書かれたキャンセル用 URL / ホーム画面の予定詳細

## 3. カレンダー連携の仕様

### 3.1 連携できるカレンダーと設定場所

- 対応: **Google カレンダー(Gmail / Google Workspace)** と **Outlook 予定表(Microsoft 365 / Outlook.com / Outlook.jp / Hotmail.com)**。オンプレミス版の Microsoft アカウント(Exchange Server)は不可
- 設定場所: 「アカウント設定 > 連携カレンダー」(ユーザー単位の設定。日程調整カレンダー単位では選べない)
- 設定項目(原文の項目名ベース)
  - **空き時間を表示するカレンダー**(= 予定の重複を確認するカレンダー): 連携アカウント内のカレンダーから**最大2つ**選択
  - **どのカレンダーに予定を登録しますか?**(= 予定を登録するカレンダー): **1つだけ**。デフォルトアカウント(登録に使ったアカウント)内のカレンダーのみ選べる
  - **追加連携アカウント**: サブアカウントを**1つ**追加可能。そのアカウントのカレンダーは「空き時間を表示するカレンダー」には選べるが、予定の登録先にはできない
  - **ステータスが「予定あり」の終日予定を「予定なし」として扱う**(チェックボックス、デフォルト OFF)
- 「空き確認用」と「登録先」を別カレンダーにするとダブルブッキングの恐れがあるため、同一カレンダーが推奨されている
- TimeRex 上のカレンダー名は普段の表示名と異なることがある(Google: 「<メールアドレス>のカレンダー」、Outlook: 「Calendarのカレンダー」「予定表のカレンダー」)
- 他人の共有カレンダー・祝日カレンダー・購読カレンダーを選べるか、書き込み権限の条件は記事に記載なし(未確認)

### 3.2 どの予定を「予定あり(候補に出さない)」とするか

公式ヘルプ「どのように登録された予定が『空き時間』と判定され、日程候補として表示されますか?」の内容。

**Google カレンダー**

| 予定の状態 | 候補として表示されるか(= 空きとみなすか) |
|---|---|
| ステータス「予定なし」の予定 / 終日予定 | 表示される(空き扱い) |
| ステータス「予定あり」の予定 / 終日予定 | 表示されない(埋まり扱い) |
| サイレントモード / 不在 / 予約スケジュール | 表示されない |
| タスク: 「予定なし」/ 終日欄のタスク(ステータスを選べない) | 表示される(空き扱い) |
| タスク: 「予定あり」 | 表示されない |
| リマインダー | 表示される(空き扱い) |
| 招待された予定: 未回答 | **表示されない(埋まり扱い)** |
| 招待された予定: 出席(承諾) | 表示されない |
| 招待された予定: 未定(仮承諾) | **表示されない(埋まり扱い)** |
| 招待された予定: 欠席(辞退) | 表示される(空き扱い) |

**Outlook 予定表**

| 予定の状態 | 候補として表示されるか |
|---|---|
| 公開方法「空き時間」の予定 / 終日予定 | 表示される(空き扱い) |
| 「他の場所で仕事中」「仮の予定」「取り込み中(予定あり)」「外出中」 | 表示されない(**仮の予定も埋まり扱い**) |
| 招待された予定: 未回答 / 出席 / 仮承諾 | 表示されない |
| 招待された予定: 辞退 | 表示される |
| 主催者がキャンセルした予定(キャンセル済み) | 表示される |

- **終日予定**: Google も Outlook も、終日予定はデフォルトで「予定なし / 空き時間」ステータスで作られるため、**そのままだと空き扱い**になる。終日予定の日を塞ぎたい場合はカレンダー側でステータスを「予定あり」に変える
- **判別方式の変更(2025-09 告知、2026-01-26 までに全ユーザー移行)**: 以前は「終日予定があればその日は丸ごと調整不可」だったが、「ステータスが予定なし/空き時間なら空き」というステータス基準に統一された
- 「ステータスが『予定あり』の終日予定を『予定なし』として扱う」オプション: 利用環境によって終日予定が自動的に「予定あり」で登録されてしまうケースへの対処用。通常は OFF 推奨とされている(ON にすると「予定あり」の終日予定も空き扱いになる)
- **複数カレンダー**: 「空き時間を表示するカレンダー」に選んだ最大2つ(+ 追加連携アカウント内)の予定を合算して埋まり判定(詳細な合算ロジックの記述はないが、料金ページに「複数のカレンダーの空き状況から日程候補を提示する」と記載)

### 3.3 個別の予定を選んで除外/反映する機能はあるか

- **TimeRex の画面上で「この予定は無視する / 反映する」を予定単位で選ぶ機能は確認できなかった**(ヘルプ全カテゴリの記事タイトルと主要記事本文を確認した範囲)
- 代替手段は連携カレンダー側の操作のみ:
  - 無視させたい予定 → Google / Outlook 側でその予定のステータスを「予定なし / 空き時間」に変える、または招待を辞退する
  - 塞ぎたい時間 → カレンダーに「予定あり」のダミー予定を入れる(公式が「日程候補を絞る方法」の1番目に挙げている)
- TimeRex 側で候補を絞る手段は「曜日ごとの受付時間」「特定の日の受付時間(有料)」「予約受付件数の上限(有料)」のみ。公式の説明は「受付時間帯の中で、連携カレンダー上で予定が空いている日時**すべて**に日程候補を提示する仕様」
- → **Slotto の差別化候補**: 管理画面のカレンダービュー上で、予定ごとに「空きとして扱う / 埋まりとして扱う」をトグルできる機能(未回答の招待、仮の予定、終日予定の扱いをサービス側の設定で切り替えられることも含む)

### 3.4 空き判定・同期のタイミング

- 空き確認は**予定のコピーを持つ同期方式ではなく、2時点で連携カレンダーを直接読む方式**: (1) ゲストが日程調整ページを開いたとき (2) 「上記の内容で日程調整を完了する」を押したとき。公式はこれを「リアルタイムに連携」と表現している(スマホで登録した予定が Google / Outlook 側でまだ同期されていないと反映されない、という注意書きあり)
- 完了時に既存予定と重なっていたら「すでに予定が入っています」と表示し、日程選択に戻す
- 候補枠の作り方: 受付時間帯を「日程候補の表示間隔」で等分して枠を作り、その枠に「所要時間 + 前後の確保時間」が収まる空きがあれば表示。受付時間帯の途中から始まる空き(例: 15:30〜16:30)は、枠の区切りに合わなければ表示されない
- 24:00 をまたぐ枠(23:30〜24:30 など)は提示できない

### 3.5 確定した予定のカレンダーへの書き込み

- 登録先: 実際に参加メンバーになったホストの「どのカレンダーに予定を登録しますか?」で選んだカレンダー
- **ゲストはカレンダーの出席者(招待客)としては追加されない**。ゲストへは完了メールに **ICS ファイルを添付**して送る(Gmail など ICS 対応メーラーなら自動登録)。ホスト側の予定とゲスト側の予定は連動しない(片方を編集しても反映されない)
- 複数メンバーが参加する予定(2026-05-27 に仕様変更):
  - 変更前: 参加者それぞれのカレンダーに独立した予定を登録(全員が主催者)
  - 変更後: **1人が主催者、他のメンバーは同席者として招待**される形で1つの予定に。主催者は「Web会議設定 > 誰をホストとしてルームを発行しますか?」で選んだメンバー。Web会議なしの場合は「全員が参加」なら参加メンバー設定で一番左のメンバー、「2つのグループから1人ずつ」ならグループ1から決まったメンバー
  - プライマリ以外のカレンダーを連携 / Google と Outlook が混在 / 別組織の Outlook の場合は予定が2つ登録されることがある
- 前後の確保時間は別予定として登録(ホスト側のみ)
- 予定のプライバシー設定「非公開」でホスト側の予定を非公開予定として登録可能
- カレンダー上の予定に**キャンセル用 URL**が記載される(ホストはそこからキャンセル可)
- **カレンダー側で予定を削除しても TimeRex 上ではキャンセルにならない**(ゲストへキャンセル通知は飛ばず、リマインドも通常どおり送られる)。逆方向の同期はない
- カレンダーに登録される予定のタイトル形式・説明文の内容はヘルプ記事では確認できず(未確認)

### 3.6 連携エラー時

- 原因: 連携カレンダー側のセキュリティ設定変更、アクセストークンの無効化
- ゲスト側表示: 「ただいま日程候補を表示できません。現在、このページでは日程候補を表示できない状態です。ご予約をご希望の場合は、お手数ですが主催者へお問い合わせください。」
- 参加メンバー本人が開くと「原因を調べる(トラブルシューティング)」ボタンが出て再連携に誘導
- ホストへの自動通知(メール等)の有無は記事に記載なし(未確認)

## 4. チーム機能

### 4.1 スペースの考え方

- **チームスペース**: 日程調整カレンダー・予定・フォルダ・連携設定・契約の入れ物。2022-07-13 以降の新規ユーザーは登録と同時にチーム(フリープラン)が1つ自動作成される
- **マイスペース**: 自分だけのスペース(メンバー追加不可)。2022-07-12 以前に登録したユーザーだけが持つ旧来の仕組み。「候補を選んで日程調整」「ルーティング」はマイスペース非対応
- 1ユーザーが複数チームに所属可能。画面左上のチーム名をクリック →「スペースの切り替え」欄で選択。「+スペースを追加」で新しいチームを作成(チーム名・チームID を入力)
- ホーム画面の内容(日程調整カレンダー、予定、フォルダ)はスペースごとに別
- チームの人数上限: フリー 100人 / ベーシック・プレミアム 無制限(ライセンス数分)

### 4.2 参加メンバーと参加方式(複数人の空き時間の AND / OR)

日程調整カレンダーごとに「参加メンバー」と「参加方式」を設定する。

| 参加方式 | 空き判定 | プラン |
|---|---|---|
| 全員が参加 | 候補メンバー**全員が空いている**時間だけを候補に出す(AND) | 全プラン(フリーは2人まで) |
| 誰か1人が参加 | 候補メンバーの**誰か1人でも空いていれば**候補に出す(OR)。確定時に1人を自動アサイン | 全プラン(フリーは2人まで) |
| 2つのグループから1人ずつ参加 | グループ1・グループ2 のそれぞれで1人以上空いている時間を候補に出し、各グループから1人ずつアサイン(例: 営業1人 + SE 1人)。同じメンバーを両グループには入れられない | ベーシック以上 |

- 選択できるメンバー数は方式に関わらず**最大12人**(フリーは2人)
- 「必須メンバー + 誰か1人」のような AND と OR の自由な組み合わせは、上記「2つのグループ」以外に記述なし(未確認。固定メンバーをグループ1に1人だけ入れれば「Aさん必須 + グループ2の誰か」は実現できると推測)

### 4.3 担当者の自動割り当て(参加メンバーの決定方法)

グループ内に2人以上いる場合の決定方法を選ぶ。

| 決定方法 | ロジック | プラン |
|---|---|---|
| 均等(日程候補優先) | 誰か1人でも空いていれば候補を出す。ゲストが選んだ日時に対応可能なメンバーのうち、**その日程調整カレンダーでの担当件数が最も少ない人**にアサイン。同数ならランダム | 全プラン(公式サイトの説明では「ランダム」と表現) |
| 均等(担当件数優先) | **担当件数が最も少ないメンバーの空き時間だけ**を候補として出し、その人にアサイン。他の人が空いていても出さない(機会損失の可能性あり)。「誰か1人が参加」のときのみ選択可 | ベーシック以上 |
| 優先度順 | 設定した優先順位が高いメンバーから順にアサイン | ベーシック以上 |

- 担当件数は**期間の制限なく累計**(確定で +1、キャンセルで -1)。日程調整カレンダー単位のカウントで、カレンダーをまたいだ合算はない
- 予約受付件数の上限(ベーシック以上)と併用でき、上限に達したメンバーは候補から外れる
- 会議室も同様に「優先順位」で1室を決定(最大5室)

### 4.4 メンバー管理・招待

- フリープラン: **招待リンク方式**。メンバーなら誰でも発行可。有効期限 48 時間、1つのリンクで複数人が参加可。参加者の権限は自動で「メンバー」
- ベーシック / プレミアム: **メールアドレス指定の招待のみ**(招待リンク不可)。招待時に権限を指定。招待中の人も含めてライセンスが必要
- メンバー管理画面: アクティブなメンバー一覧(氏名、メールアドレス、権限、各種連携状況、タイムゾーン)、招待中のメンバー、権限変更、削除
- ライセンス数自動調整設定(オーナーのみ)

### 4.5 権限(ロール)

| 権限 | ライセンス | 参加メンバーに設定 | できること |
|---|---|---|---|
| オーナー | 消費する | 可 | すべて(チーム情報・契約期間・クレジットカードの変更、チーム削除、オーナーのみの操作を含む) |
| 管理者 | 消費する | 可 | チーム/契約情報の閲覧、メンバーの招待・削除・権限変更、ライセンス購入、支払い履歴・領収書、日程調整カレンダーの閲覧・作成・編集・削除 |
| メンバー | 消費する | 可 | 日程調整カレンダーの閲覧・作成・編集・削除(チーム内の全カレンダー)。フリープランではメンバー招待も可 |
| ライトメンバー | 消費する | 可 | **自分が参加メンバーになっているカレンダー/予定の閲覧のみ**。作成・編集・削除・CSV エクスポート不可(2026-01-13 リリース) |
| 管理アシスタント | **消費しない** | **不可** | 管理者と同じ操作権限(本人は予定に参加しない。秘書・営業事務向け) |
| アシスタント | **消費しない** | **不可** | メンバーと同じ操作権限(本人は予定に参加しない) |

- アシスタント系の無償ライセンスはベーシック以上
- フォルダ単位のアクセス制御(「チーム全員に共有する」/「メンバーを限定する」)がベーシック以上で使える。フォルダ作成自体は全ユーザー可。フォルダを削除すると中の日程調整カレンダーも削除される。フォルダの階層化(入れ子)は記述なし
- アクティビティログ(ベーシック以上、オーナー・管理者・管理アシスタントが閲覧): ログイン/ログアウト、アカウント設定変更、チーム設定変更、契約変更、日程調整カレンダーの作成/更新/削除、外部サービスの連携/解除。列は「日時 / 画面 / アクション / メンバー / 概要」、日時・画面・メンバーで絞り込み

## 5. 外部連携

連携設定は3階層ある: **アカウント設定 > サービス連携**(個人単位)/ **チーム設定 > サービス連携**(チーム単位)/ **日程調整カレンダーの詳細設定 > サービス連携 >「サービス連携を追加する」**(カレンダー単位で有効化)。

### 5.1 Web会議(全プラン)

| ツール | 連携単位 | 条件 | 備考 |
|---|---|---|---|
| Zoom | ユーザー単位(アカウント設定 > サービス連携 →「連携する」→ Zoom の認可画面) | Zoom アカウント | パスコード・待機室の有無は Zoom 側の設定で変更。PMI は連携では使えず、メッセージ欄に固定 URL を書く運用 |
| Google Meet | ユーザー単位 | **Google アカウントで TimeRex に登録したユーザーのみ**(Microsoft 登録ユーザーは不可)。TimeRex アカウントに紐づく Google アカウントのみ | 発行 URL はホストの Google カレンダーの予定に記録 |
| Microsoft Teams | ユーザー単位 | **Microsoft 365 法人アカウント**(Business Basic / Standard / Premium)が必要 | ゲストがキャンセルすると紐づく Teams 会議は削除される |

- 日程調整カレンダーの「Web会議・会議室設定」で「利用しない / Zoom / Google Meet / Microsoft Teams」を選ぶ。複数メンバーの場合は「**誰をホストとしてルームを発行しますか?**」で発行者(= カレンダー予定の主催者)を選ぶ

- 「ゲストに対して Web会議URL を非公開にする」オプションあり
- 同じ Web会議アカウントを複数の TimeRex アカウントに連携することは不可(Meet / Teams で明記)
- 固定の会議 URL を使いたい場合は Web会議設定を「利用しない」にして、「日程調整完了時に表示するメッセージ」に URL を書く
- **対面・電話・住所などの「場所」を選ぶ専用設定は確認できず**(セミナー機能には「ウェビナーURL または住所」欄がある)

### 5.2 チャット通知(全プラン)

- **Slack**: チーム設定でワークスペースを連携(オーナー・管理者・管理アシスタント)→ 日程調整カレンダーごとに通知先チャンネルをプルダウンで選択。1カレンダーにつき1チャンネル、1チームで合計60件まで。パブリック/プライベートチャンネルのみ(DM 不可、プライベートは bot を招待)
  - 通知イベント: 日程調整完了 / キャンセル / リスケジュール / グループ投票の回答入力 / グループ投票の日程確定
  - 通知内容: カレンダー名(リンク)、確定日時、参加者、詳細へのボタン、非公開カレンダー名
- **Chatwork**、**Microsoft Teams Chat** も同種の通知連携(詳細は未読)
- LINE 連携はなし(レビューで要望あり)

### 5.3 CRM(プレミアム)

- **Salesforce**(API アクセス可能なエディションが必要): チーム設定で接続 → カレンダーごとに設定
  - 連携先: リード / 取引先責任者 / リードと取引先責任者(自動判定)
  - 重複判定: ゲストのメールアドレス一致(複数一致時は作成日時が最も古いレコード)
  - 「データの連携形式」: 上書きする / 上書きしない。「新規行動の登録」: 登録する / しない
  - 行動(Event)の登録内容: 件名 = 非公開カレンダー名(なければカレンダー名)、割当先 = 参加メンバー、場所 = Web会議URL、開始/終了、種別 = Meeting、説明 = 予定詳細・質問回答など。キャンセルで行動を削除、リスケで日時を更新
  - 姓・名の分割に AI を利用する項目あり
- **HubSpot**: チーム設定で接続 → カレンダーごとに設定。連携先は「会社」「コンタクト」オブジェクト(文字列/数値プロパティ、カスタム含む)。重複判定は会社名またはドメイン / コンタクトは E メール。180日間連携がないとトークン失効
- **フォーム POST**: 日程調整完了時に、指定した HTTPS のフォーム URL へゲスト情報を POST(パラメータ名と値のマッピングを設定。予定開始日時、キャンセルリンク、リスケリンク等も送れる)。キャンセル時は送信されない。動作保証は Salesforce と HubSpot のフォームのみ

### 5.4 自動化・開発者向け(全プラン)

- **Zapier**: トリガー3種 — Event Created(日程調整完了)/ Event Cancelled / Event Rescheduled。予定日時、ゲスト名、メール、アップロードファイル等を渡せる
- **Webhook**: 「TimeRex で特定のイベントが発生したときに、指定した URL に POST」。すべてのユーザーが利用可。設定は チーム設定 > デベロッパーツール。イベント種類・ペイロード・署名検証・リトライの詳細は Developer Portal のリファレンス(SPA のため本文取得できず、**未確認**)
- **日程調整API**(2022-10-25 提供開始、利用無料): 自社サービスに日程調整機能を組み込む用途。OAuth クライアントを作成して利用。APIキー認証もあり(Chrome 拡張機能の認証に使う)。エンドポイント一覧は**未確認**(同上)
- **Chrome 拡張機能**: よく使う日程調整カレンダーをお気に入り登録し、URL コピー / ワンタイムURL 発行をブラウザのツールバーから行う。認証は APIキー(オーナーまたは管理者が チーム設定 > デベロッパーツール で発行)
- チーム設定 > セキュリティ に「API連携許可設定」がある

### 5.5 データ出力・計測

- **Google Sheets**(全プラン): アカウント設定で Google を連携 → カレンダーごとに有効化するとスプレッドシートを自動作成(「Events」シート)。確定で行追加、キャンセルで該当行のステータスを「キャンセル」に、リスケで旧行を「日程変更済み」+ 新行追加
  - 列: イベントID、スケジュール(日時・タイムゾーン)、Web会議URL、ステータス、キャンセル理由、キャンセル実行者、参加メンバー、送信日時、ゲスト情報、種別(新規/日程変更)、old_event_id / new_event_id、非公開カレンダー名、質問の回答、アップロードファイルの URL
- **CSV エクスポート**(プレミアム): 「予定」タブ →「CSVエクスポート」→ 期間指定(最大6ヶ月)。ホーム全体またはフォルダ単位
- **Google Analytics**(プレミアム): 日程調整ページの PV・コンバージョン計測
- **広告コンバージョンタグ**(プレミアム): Google 広告 / Facebook 広告
- **URL パラメータ**: `<予約ページURL>?campaign=webinar` のように任意パラメータを最大25個付与。予定詳細・連携カレンダーの予定・ホスト向け完了メール・CSV・Webhook に記録される(ゲスト向けメールには載らない)。確認できるのはプレミアムのみ
- **質問項目の事前入力**(記事上は全プラン): `guest_company` / `guest_name` / `guest_email` / `guest_comment`、カスタム質問は `<custom_form_field_id>=<値>`

### 5.6 サイト埋め込み(ウィジェット)

- 日程調整カレンダー詳細ページの「埋め込み」ボタンからスクリプト(HTML タグ)を取得し、サイトの body に貼る。iframe ではなく JS ウィジェット(`TimerexCalendar({...})`)
- レスポンシブ対応。基本1ページ1ウィジェット
- カスタマイズ(プレミアム): `primary_color`(キーカラー)、`disable_logo`(ロゴ非表示)、`disable_title_hyperlink`、`locale`(en など)
- Callback 機能で親ページにイベントを返せる(GTM 発火などに利用)
- ルーティングは埋め込み非対応

### 5.7 その他

- **デジタル名刺**(全プラン): Sansan / Eight / Sansan名刺メーカー。完了画面と完了メールに名刺交換ボタンを表示
- **会議室**(ベーシック以上): Google Workspace / Microsoft 365 の会議室リソースを確保
- **決済連携: 公式の料金ページ・機能ページ・ヘルプセンターには決済(Stripe / PayPal 等)機能の記載なし**。個人ブログに「Stripe と連携して事前決済できる」との記述があったが出典がなく、Zapier 経由の話と推測(未確認)。→ 有料予約は TimeRex の弱い領域で、Slotto が差別化するなら候補になる

## 6. ゲスト(予約する側)の体験

### 6.1 前提

- **ゲストは TimeRex のアカウント登録・ログイン不要**。URL を開いて日時を選び、名前とメールアドレスを入れるだけ
- 用語: TimeRex ではゲスト向けの予約ページを「**日程調整ページ**」と呼ぶ(ホストが作る設定のまとまりが「日程調整カレンダー」)
- 対応ブラウザ: Windows(Chrome / Edge)、Mac(Chrome / Safari)、iOS(Safari)、Android(Chrome)の各最新版
- 言語: 日本語 / 英語。タイムゾーンはゲストの環境に合わせて自動変換(Mac は OS、Windows・スマホはブラウザのタイムゾーン)

### 6.2 画面遷移(日程調整カレンダー / ワンタイムURL)

全画面共通: 上部に TimeRex ロゴ、右上に「サポート」「ログイン」。白いカードの中に「所要時間 60分」バッジ、カレンダー名(大見出し)、**3ステップのステッパー「(1) 日程選択 → (2) 情報入力 → (3) 日程調整完了」**(現在のステップがティール色で強調、済みステップはチェックマーク)。以下はヘルプ記事内の画面キャプチャ(2026-08 撮影)を目視確認した内容。

**画面1: 日程調整ページ(日時選択)**

- 見出し「ご都合の良い日時を選択してください」
- 右上に案内バナー「ログインすると、あなたの予定もこのページで確認できるようになります。」+「**新規登録(無料)**」ボタン(= ゲストを新規ユーザーに転換する導線)
- 「日程調整開始時に表示するメッセージ」(ホストが設定した場合)
- **週カレンダー型のグリッド**: 上部に年月(「2026年8月」)、**タイムゾーン表示「アジア/東京 (UTC+09:00)」+ 歯車アイコン**(変更用と推測)、左上「< 前へ」・右上「次へ >」
- **1ページ = 5日分の列**(例: 15 土 / 16 日 / 17 月 / 18 火 / 19 水)。土日も列として表示され、候補がなければ空欄
- 縦軸は時刻(左右両側に 11:00, 12:00 … のラベル)。**候補枠はティールグリーンで塗られたブロック**に「10:00 - 11:00」と時間帯が書かれ、クリック/タップで選択
- スマホではページ送りが右上の「<」「>」ボタンになる
- 候補がない場合は最大5ページ(25日間)先まで自動でページ送り
- 縦の時間軸は候補の状況に応じて伸縮。候補が1つ以上あれば最小でも9時間幅を表示、最も早い時間帯が上
- カレンダーの下: 「日程候補が合わない場合」+「**主催者に知らせる**」ボタン(ホストが有効化している場合のみ)
- 候補がない期間: 「この期間に候補日程はありません。次の期間をご確認ください。」
- **ゲストが TimeRex にログイン中の場合、ゲスト自身の連携カレンダーの予定がグレーで重ねて表示**される(トグルでオン/オフ)。ホストの予定の中身がゲストに見えることはない
- 受付停止中: 「ただいま予約受付は停止中です。」/ 受付期間外: 「アポイント一覧を取得できませんでした ただいま受付期間外です。」/ 連携エラー: 「ただいま日程候補を表示できません。…主催者へお問い合わせください。」

**画面2: 情報入力**

- 「日程」ボックス: 選んだ日時「8月17日(月) 12:00 - 13:00」、タイムゾーン「アジア/東京 (UTC+09:00)」、右に「**日程選択に戻る**」ボタン

- URL パラメータで事前入力されている場合あり
- 送信ボタンの直上に「利用規約・プライバシーポリシーに同意し」のリンク付き文言(チェックボックスではなく、ボタン押下 = 同意の形式)
- 送信ボタン: 「**上記の内容で日程調整を完了する**」(英語: Complete booking)
- ボタンの下に小さく「不正行為を報告する」リンク
- 押した時点で空きを再確認。埋まっていたら「すでに予定が入っています」と表示して日時選択に戻す
- 確認画面(入力内容の確認ステップ)は挟まない。日時選択 → 入力 → 完了 の3画面

**画面3: 完了画面**

### 6.3 予約後に届くもの

- **日程調整完了メール**(送信元ドメイン @timerex.net): ICS ファイル添付、Web会議 URL、キャンセル用 URL、リスケジュール用 URL(「予定を変更する」リンク)、ホストのメッセージ
- カレンダー招待(ホストの予定にゲストを出席者として追加する方式)ではなく **ICS 添付方式**。Gmail など対応メーラーなら自動でカレンダーに入る。ホストが完了メール送信をオフにしていると ICS も届かない(完了画面の文言は「予定の招待を送信しました」)
- 完了画面の「Googleカレンダーに追加する」「カレンダーアプリに追加する」ボタンからも自分で登録できる
- **リマインドメール**: 予定の前日 16:00(ゲストのタイムゾーン)に1回。ホスト設定でオフ・時刻変更・メッセージ追加が可能
- 日程変更時・キャンセル時にもそれぞれメールが届く

### 6.4 キャンセル / 日程変更の流れ(ゲスト)

1. 完了メールの「**予定を変更する**」リンクを開く(ログイン不要)
2. 「日時の変更」または「予定のキャンセル」を選ぶ
3. 日時の変更: 候補から新しい日時を選んで完了(元の予定はキャンセル扱いになり、新しい予定が作られる。ホストには「キャンセル + 新日時で確定」を1通にまとめたメール)
4. キャンセル: 内容を確認し、任意でコメント欄に理由を書いて「予定をキャンセルする」
- 期限: デフォルトは予定の**終了時刻まで**可。ホストがベーシック以上なら「開始の N 時間前まで」に制限できる
- 日程調整カレンダーが削除済み・受付停止中の場合は、日時変更はできずキャンセルのみ
- 「候補を選んで日程調整」「グループ投票」は仕様が異なる(グループ投票はゲストによる回答変更・キャンセル不可)

### 6.5 その他のゲスト体験

- グループ投票: 候補ごとに ○ / × を選び、名前・メールアドレスを入力して送信。確定後に ICS 付きメール
- セミナー: 開催日程を選んで申込。仮予約制の場合は「参加をリクエストしました」→ ホスト承認後に確定メール。キャンセルは確定メールの「申込をキャンセルする」
- ルーティング: 最初に質問に回答 → 条件に応じた日程調整カレンダーが表示される(または「メッセージ」が表示されて終了)
- ウィジェット埋め込み: ホストのサイト内でページ遷移なしに同じフローを完了

## 8. サインアップ/ログイン方式、予約ページの URL 構造

### 8.1 サインアップ / ログイン

- **Google アカウントまたは Microsoft アカウントでの OAuth ログインのみ**。メールアドレス + パスワードの登録はなく、TimeRex 独自のパスワードは存在しない
- 登録できるアカウント: Gmail、Google Workspace、Microsoft 365、Outlook.com、Outlook.jp、Hotmail.com(オンプレミス版 Microsoft は不可)
- 登録ページ(https://timerex.net/try-free): 「お持ちのカレンダーのアカウントで今すぐ登録」/ ボタン「Googleで登録」「Microsoftで登録」/ 「利用規約とプライバシーポリシーに同意して登録」/ クレジットカード不要
- ログインページ(https://timerex.net/auth/login): 「Googleでログイン」「Microsoftでログイン」のみ
- ログイン = カレンダー連携(登録に使ったアカウントが「デフォルトアカウント」になり、予定の登録先はそのアカウント内のカレンダーに限られる)
- Google 登録時はカレンダーへのアクセス許可をすべてチェックして続行する必要がある。Microsoft は組織設定により「管理者の承認が必要」と表示されて登録できないケースがある(専用のヘルプ記事が2本ある = つまずきやすい箇所)
- 初回設定ウィザード: (1) 表示名(ゲストに見える名前)(2) 連携カレンダーの選択 →「初回設定を完了する」→「TimeRexをはじめる」→ ホーム画面。登録と同時にフリープランのチームが自動作成される
- 登録メールアドレスの変更、SSO / SAML については記事を確認していない(未確認)
- iCloud カレンダー、Yahoo! カレンダー、サイボウズ等は非対応(レビューで不満として挙がっている)

- `<カレンダーID>`: カレンダーごとに**ランダム生成**(例示は `abcdef`)。**ユーザーが任意の文字列(スラッグ)に変えることはできない**
- → レビューの「URL に担当者名が入っていれば判別しやすいのに」という不満の原因。Slotto ではカレンダーごとのスラッグを編集可能にすると差別化になる
- URL パラメータ: `?guest_name=...&guest_email=...`(事前入力)、`?campaign=...`(任意の流入元情報、最大25個)
- ワンタイムURL、キャンセル/リスケ用 URL、グループ投票 URL の具体的な形式は未確認

## 9. モバイルアプリの有無、スマホでの使い勝手

- **TimeRex のネイティブアプリ(iOS / Android)は確認できなかった**。App Store / Google Play を対象にした検索でも、ヒットするのは同じミクステンド社の別サービス「調整さん」のアプリ(2023-10 提供開始)のみ。公式サイト・ヘルプセンターにもアプリの案内なし
- 提供形態は Web(レスポンシブ)。サポートブラウザに iOS Safari / Android Chrome の最新版が含まれる
- ゲスト側はスマホ対応(ページ送りが「<」「>」ボタンになるなどスマホ用レイアウトあり)
- ホスト側(管理画面)はスマホのブラウザでも開けるが、**PC でしか使えない機能**が明記されている:
  - 「候補を選んで日程調整」のページ作成(ゲスト側の確定操作はスマホ可)
  - ルーティングの作成
  - フォルダの並び替え
- 補助ツールとして **Chrome 拡張機能**(2026-07 リリース)があり、TimeRex を開かずに URL コピーやワンタイムURL 発行ができる(PC 向け)
- プッシュ通知はなく、通知はメールと Slack / Chatwork / Teams Chat
- ITreview には「スマホからも対応できる」という好意的な声がある一方、スマホでの管理操作の詳細なレビューは見つからなかった
- → **Slotto がモバイルアプリを出す場合の差別化ポイント**: 外出先での URL コピー / ワンタイムURL 発行、予約のプッシュ通知、当日の予定一覧、ホスト側からのリスケ・キャンセル、候補の手動選択をスマホで完結させる、など TimeRex が PC 前提にしている操作

## 10. 公式が訴求している強みと、レビューで挙がっている不満点

- Zoom / Microsoft Teams / Google Meet の URL 自動発行
- 柔軟な日程調整方式(1:1、全員参加、誰か1人、2グループ、投票、候補指定、セミナー、ルーティング)
- 3,000 以上の外部サービス連携(Zapier 経由を含む数字)、Salesforce / HubSpot、Webhook / API(API は無料)
- サイト埋め込みウィジェット、Google Analytics、広告コンバージョン計測(マーケ・インサイドセールス用途)

- 実績: 登録者数60万人突破、導入企業ロゴ(リクルート、Sansan、マネーフォワード、丸紅、コクヨ等)、運営は「調整さん」(月間800万人以上利用)のミクステンド
- 英語・タイムゾーン対応、ゲストはログイン不要
- 価格: 1ライセンス月 750円〜で、比較記事では Spir など競合より安価と評価されている
